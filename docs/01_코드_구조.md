# 잔흔(Scars) — 코드 구조

Unity 2022.3 / 2D / TextMeshPro / 입력은 예전 Input Manager(`activeInputHandler: 0`).
레퍼런스: The Case of the Golden Idol(추리 구조) · Tangle Tower(UI·탐색) · Lamplight City(분위기·분기 구조).

> **지금은 뼈대만 있다.** 클래스와 빈 함수만 있고, 기능·데이터 필드·이야기 내용은 없다.
> 기능은 하나씩 차근차근 채운다. ✅ = 구현됨.
>
> 구현 순서(기능 먼저, UI는 확정 후): ① GameState+ClueInventory ✅ → ② 데이터 최소 필드(id) ✅ → ③ QuizSession ✅ → ④ HypothesisBoard ✅ → ⑤ DialogueRunner ✅ → ⑥ GameManager → ⑦ SaveSystem. 보류: Hotspot·ZoomView·InputRouter·AudioManager·View류.

## 화면·씬 구성

- **씬은 장소 단위**: 사무소(Phase 1) / 복도(Phase 2·5) / 서재(Phase 3·4). GameManager는 씬이 바뀌어도 유지한다.
- **서재 = 씬 1개**. 그 안에 동·서·남·북 방향 오브젝트 4개(각각 배경 그림 + 그 벽의 Hotspot 자식)를 두고, 좌우 화살표로 현재 방향만 켠다. 방향을 씬으로 나누지 않는 이유: 전환이 즉시이고, 조사 상태가 그대로 유지되며, 공통 UI를 한 번만 두면 된다.
- 방향 오브젝트는 **각각 프리팹**으로 만들어 동시 작업 충돌을 줄인다.
- 확대 조사·일지·가설창은 같은 씬 위에 덮어 띄우고, 우클릭 닫기는 ScreenStack이 맡는다.
